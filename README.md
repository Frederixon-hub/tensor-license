# Список отзыва лицензий Tensor

`revocations.tlr` — список отозванных лицензий семейства программ Tensor. Программы скачивают его
по адресу

    https://raw.githubusercontent.com/<владелец>/tensor-license/main/revocations.tlr

вскоре после запуска и каждые 4 часа.

Файл подписан ключом поставщика (Ed25519): изменённый вручную, поддельный или более старый список
программы не принимают. Не редактируйте его здесь — новый список подписывает и публикует утилита
`scripts/license/revoke.cjs --publish` в проекте Tensor.

В файле только номера лицензий, коды машин и даты; имён и адресов в нём нет.
